## Decision I already make

I write down decision when I make it. If you do not write it down, then later everybody
argue about it and nobody remember why, and it is your fault.

- **Name is SeeFood.** Not negotiable. I have the name before I have the app. This is
  correct order.
- **Phone only. No web.** Nobody take picture of their dinner with laptop.
- **One button. Camera open when app open.** If user must press two thing, it is not
  Shazam for food, it is menu.
- **Train on hotdog first.** Not because app is about hotdog. Because I have many
  picture of hotdog and you start where the data is. This is engineering.
- **No cloud yet.** Cloud cost money. I have no user. When I have user, then cloud.
- **No login.** Why you need account to look at hotdog.
